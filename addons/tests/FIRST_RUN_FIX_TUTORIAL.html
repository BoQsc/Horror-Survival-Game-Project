Town Stall Vulkan Runbook

This branch keeps the project on Forward+ Vulkan and uses the existing GDExtension DLLs. The x5 profile caps near terrain at 30 and pushes streaming progress harder without enabling the experimental terrain LOD path.

Do not reintroduce fallback render paths. The goal here is to keep Vulkan stable and reduce terrain stream pressure.

1. Prerequisites

  1. Run from the repo root: C:\Users\Feder\Documents\Best Game 4 (Horror Survival Sandbox).
  2. Use the Godot tools binary at C:\Program Files (x86)\Steam\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe.
  3. Keep the existing DLLs in gdextension\bin\.

2. Build native DLLs if needed

cd C:\Users\Feder\Documents\Best Game 4 (Horror Survival Sandbox)\gdextension
python build.py

3. Run the test

cd C:\Users\Feder\Documents\Best Game 4 (Horror Survival Sandbox)
$env:TOWN_STALL_RENDER_DISTANCE='50'
python .\addons\tests\run_town_stall_test.py

4. What the launcher does

When TOWN_STALL_RENDER_DISTANCE is above 30, the launcher automatically: 

TOWN_STALL_TERRAIN_RENDER_DISTANCE=30
TOWN_STALL_TERRAIN_STREAM_MOVEMENT_CHUNK_LIMIT=4
TOWN_STALL_TERRAIN_FORCE_STREAM_PROGRESS=1
TOWN_STALL_TERRAIN_FORCE_PENDING_NODE_FINALIZATION=1
TOWN_STALL_WORLD_MAP_VISUAL_BATCH_PROFILE=1

5. Success criteria

  1. The launcher prints the high render-distance profile line with the terrain cap.
  2. Godot starts with --rendering-driver vulkan --rendering-method forward_plus.
  3. The log shows Vulkan 1.4.341 - Forward+ - Using Device #0: NVIDIA GeForce RTX 4090.
  4. The harness reaches Hold started and writes a performance snapshot.

This keeps the test on the stable terrain streaming path and avoids flipping the experimental terrain LOD toggles that were causing confusion.
