# Legacy Town Launchers

These launchers are retained for historical reference and diagnostics only.

Do not use these files as the main FPS or wattage baseline. Several of them use
older cases, periodic snapshots, different hold lengths, or manual-play settings
that make results hard to compare with the locked baseline.

Use this instead for code comparisons:

```text
addons\tests\run_locked_town_baseline_v1.cmd
```

Use this for manual feel checks:

```text
addons\tests\run_manual_town_play_no_snapshots.cmd
```
